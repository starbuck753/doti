# Doti

Phase 0 foundation for a local-first checklist app.

## Included

- React + TypeScript + Vite
- React Router route skeleton
- Dexie/IndexedDB database schema
- English/Spanish translations with i18next
- Light/dark theme using CSS variables
- Placeholder routes for tasks, task detail, birthdays, notes, note detail, completed tasks and settings

## Intentionally deferred

Task behavior, priority aging, Markdown, swipe interactions, PWA/service worker, Capacitor, synchronization and backend services.

## Run

```bash
npm install
npm run dev
```
